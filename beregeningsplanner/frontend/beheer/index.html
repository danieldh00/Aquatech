Aquatech Beheer

Elke regel is een aanvraag: een nieuw plan, een reeks wijzigingen (binnen een half uur samengevoegd), een verwijdering of een automatische planherkenning. De historie is alleen voor beheerders zichtbaar en blijft bewaard, ook als een gebruiker het plan verwijdert.

Alle actuele plannen van alle gebruikers. Gebruikers zien zelf alleen hun eigen plannen.

Gebruiker toevoegen

Instellingen van de app. Ze staan in de database van de app en werken meteen, zonder herstart en zonder Home Assistant-configuratie. Een waarde uit Home Assistant of de Docker-omgeving geldt alleen zolang hier niets is opgeslagen.

Automatisch herkennen met AI

Plan laden en laten herkennen via de Claude API van Anthropic. Zonder sleutel of uitgeschakeld gebruikt de planner de lokale herkenning; tekenen en de toverstaf werken altijd.

API-sleutel
Aan te maken via console.anthropic.com → API Keys. De sleutel wordt nooit teruggestuurd naar de browser; je ziet alleen de laatste 4 tekens.

Toegang

Met een toegangscode moet iedereen buiten het Home Assistant-paneel inloggen; wie met de code inlogt is beheerder. Zonder code is de app openbaar en werkt iedereen als gast (alleen eigen plannen). Gebruikers met een eigen account beheer je op het tabblad Gebruikers.

Toegangscode
Een nieuwe code logt alle toestellen uit die met de oude code zijn ingelogd (jij blijft ingelogd).

Modules op het dashboard

Uitgezette modules verdwijnen van het dashboard. Beheer blijft altijd zichtbaar voor beheerders.
